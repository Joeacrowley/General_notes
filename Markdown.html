2.1 Nesting tabs

The code for the producing nested tabs with a loop is illustrated below.

Note the lower level header is exactly one level lower than the top header.

Note the ::: {.panel-tabset} / ::: system is for .qmd files only, with .Rmd files you simply write ## {.tabset} after the higher level header, and it cuts out after you write another header of that level.

The code here is visible only because I’ve duplicated it outside the {r} chunk so it unevaluated, usually it is invisible.


# ### Level 3 Header

2.1.2 Applying to ggplot

The only real change from the table version is that you assign the plot to p and call print(p) — the same rule applies as with kable(): inside a loop, ggplot objects must be explicitly printed or knitr drops them silently.

Mixing tables and plots — since both print(knitr::kable(…)) and print(p) work inside the same results=‘asis’ loop, you can easily render a plot and a summary table per tab just by calling both prints before the closing cat(“”).

# ### Cylinder Groups {.unnumbered}
# 
# ::: {.panel-tabset}
# ```{r, results='asis'}
# library(ggplot2)
# 
# groups <- split(mtcars, mtcars$cyl)
# 
# for (cyl_group in names(groups)) {
#   cat("##### Cylinders:", cyl_group, "\n\n")
#   
#   p <- ggplot(groups[[cyl_group]], aes(x = wt, y = mpg)) +
#     geom_point(colour = "steelblue", size = 3) +
#     geom_smooth(method = "lm", se = FALSE, colour = "firebrick") +
#     labs(
#       title = paste("Cylinders:", cyl_group),
#       x     = "Weight (1000 lbs)",
#       y     = "Miles per Gallon"
#     ) +
#     theme_minimal()
#   
#   print(p)
#   
#   cat("\n\n")
# }
# ```
